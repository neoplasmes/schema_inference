# Визуальная и браузерная проверка

Финальная независимая проверка пройдена в согласованных границах задачи: семь обязательных сцен, 20 вручную просмотренных сравнений и 20 из 20 браузерных сценариев. Неожиданных исключений страницы нет. Открытых существенных визуальных дефектов не осталось. Эталонами служат исходные PNG; собственные снимки реализации не утверждают себя как baseline. Согласованные отличия и непроверенные возможности перечислены ниже.

После последней замены символа диапазона на ASCII-дефис повторно сняты все семь сцен и 20 сравнений без ошибок страницы. Лично повторно просмотрены anatomy целиком и product crop: `Rows 3-7 of 412` читается полностью, новых смещений или обрезания нет. Эти снимки обновляют полный `actual/results.json`; 20 браузерных сценариев для одной замены символа не повторялись.

При Node 22.15.0 на PATH:

```sh
pnpm --dir apps/editor visual
pnpm --dir apps/editor exec tsx visual/browser.ts
```

Визуальная команда использует работающий HTTP-сервер на порту 3010 либо запускает и завершает собственный. `EDITOR_URL` задаёт существующий адрес, `EDITOR_DESIGN_ROOT` задаёт внешний пакет дизайна. Runner ждёт готовности fixture, раскладки, шрифтов, фактического render и двух animation callbacks. Снимок включает весь viewport с HTML-панелями. Области сравнения записаны в `playground/references.ts`.

Среда: Node 22.15.0, Playwright 1.54.1 и соответствующий ему Chromium 139.0.7258.5; Linux x64, WSL2 6.6.87.2, AMD Ryzen 7 7840HS, DPR 2. Флаги: `--use-gl=swiftshader --enable-unsafe-swiftshader`. WebGL 2 сообщает ANGLE/Vulkan 1.3.0, SwiftShader Device (Subzero). Дополнительный `--use-angle=swiftshader` также работает, но здесь не нужен. Это программный renderer; аппаратная GPU-производительность не доказана.

HTML-эталоны подменяют SF Pro локальным Inter. Inter отсутствует: фактически используются DejaVu Sans и DejaVu Sans Mono. Доказательства шрифтов и среды сохранены в `artifacts/editor-reference/environment.json`. Все 14 HTML открыты по HTTP и измерены. Их сравнения с исходными PNG просмотрены в `reference-contact-1.png` и `reference-contact-8.png` в том же каталоге.

Процент означает наличие разницы более 24 хотя бы в одном цветовом канале. Это диагностическое число, не порог автоматического одобрения: отсутствующий текст занимает мало пикселей, но может означать существенную потерю поведения.

Артефакты: `apps/editor/visual/actual/`, `apps/editor/visual/compare/`, `apps/editor/visual/actual/browser/`. В `results.json` находятся среда, геометрия, render statistics, ошибки консоли, точные crop coordinates и метрики разницы. Для каждой сцены сохранён trace. Каждый triptych содержит эталон, фактический снимок и абсолютную разницу.

Реальным вводом уже подтверждены выбор строки, F2, Enter/Escape, состояния Undo/Redo, pan, zoom к курсору, перемещение карточки с отменой, перенос поля и Undo, перестановка XML-члена с сохранением `memberId` связи, collapse/reopen, просмотр наблюдаемого варианта без записи в семантику и добавление страницы поверх ручного переименования. Одно переименование создаёт одну операцию. Undo/Redo добавляют обратную и повторную операции в журнал неподтверждённых изменений.

Колесо над локальным окном меняет видимые поля без изменения camera и журнала операций. Boundary открывает настоящее загруженное поле; связь переходит с boundary на центр его строки. Двенадцать ArrowDown проходят за первые десять полей, сохраняя максимум десять отрисованных строк. Небольшой pan при неизменном видимом наборе сохраняет три edge Graphics и не увеличивает `edgeLayerRedraws`.

Public mount проверка обнаружила утечку изменённого fixture-документа при смене ресурса A на B. Исправление повторно проверено: A → B → A открывает чистый seed; два одновременно открытых экземпляра независимы. Native input удаляется при смене ресурса, десять немедленных mount/unmount и двойной unmount не оставляют canvas/input. Отдельный сценарий удерживает загрузку настоящего FontFace, вызывает unmount до завершения и подтверждает отсутствие позднего canvas.

HTTP-сценарий использует production adapter/controller и ответы Playwright routes: ограниченные GET manifest/node/page, перекрывающаяся страница поверх ручной правки, `If-Match`, отказ 422, исправленный запрос с новым mutation ID, ответ 202 и polling до revision s2. Он пройден. API v2 текущего backend отсутствует; тестовые HTTP-ответы не доказывают серверное сохранение или экспорт.

Первый host-прогон обнаружил HTTP 403 при смешении host `127.0.0.1` с remote `localhost`: webpack-dev-server отклоняет `sec-fetch-site: cross-site`. Согласованная пара `http://localhost:3000` и `http://localhost:3010` устраняет это ограничение dev-среды. Другой прогон выявил preload hot-update из dev federation manifest. После исправления финальные host-сценарии прошли на тёплой сборке; manifest отдельно проверен на отсутствие `.hot-update.`. React host и remote используют одну загруженную share record/library версии 19.1.0. Повтор после отказа remote загрузил настоящий canvas; CSS host совпал до, во время и после public mount, снимки до/после идентичны.

Во всех 20 сценариях нет неожиданных page errors. При намеренно оборванном remote зафиксирован ожидаемый `RUNTIME-008`; HTTP 422/404 и оборванный script также сохраняют ожидаемые console errors. Остальные сценарии не имеют console errors. Полный журнал не скрывает эти ожидаемые отказы.

Отдельный холодный запуск `pnpm --dir apps/editor visual` при остановленном сервере 3010 создал собственный webpack process, снял все семь сцен и завершил только свой process. После завершения порт 3010 успешно занят и освобождён независимым `net.Server`. Уже запущенные серверы runner использует без завершения.

Измерение чистого участка фона 180 × 80 CSS px при DPR 2 подтвердило исправление частоты зерна: отношение разницы соседей на расстоянии двух и одного device pixel составляет 1,279 у реализации и 1,282 у PNG. Средняя яркость 236,623 против 236,604. Измеренные белые строки состояний совпадают по координатам: 95, 296, 363, 430, 497, 564; высота каждой 36 CSS px. Полные данные находятся в `actual/pixel-probe.json`.

Допустимые отличия от исходника: связи доходят до фактической границы карточки вместо воспроизведения ошибки SVG на 8 px; системный шрифт отличается, как описано выше; пояснительные подписи вне доски могут исключаться явным crop; недоступные semantic replacement/export явно обозначены. Полные поля инспектора вне минимальной оболочки отложены. Эти исключения не разрешают терять состояния карточки или правильное взаимодействие.

В product полосе прокрутки сохранено семантически правильное положение бегунка возле начала: показаны строки 3-7, загружено 50 из 412. Бегунок в середине исходного PNG противоречит этим данным. Это согласованное исключение для иллюстрации; реальная прокрутка, раскрытие скрытой строки и переход клавиатурой проверяются отдельными браузерными сценариями.

Физический IME, screen reader, реальное touch-устройство, аппаратная GPU, серверное API-v2 persistence и export не проверены. Синтетические composition events проверяют только защиту Enter; CDP touch проверяет браузерные pointer events. Измерения производительности находятся отдельно в `PERF.md`.
